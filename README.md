# Self-Tape Reader

A reader for self-tapes and line learning. Upload your sides as a PDF, pick your character, and the app reads the other parts aloud. It listens for the end of each of your lines before it gives the next cue.

## Features

- Reads screenplay-format PDFs in the browser. Nothing is uploaded.
- Free browser voices, or ElevenLabs voices with your own API key. Each ElevenLabs line is generated once and saved on your device.
- Tape mode for filming, and a Learn lines mode that hides your lines, prompts you when you stall and shows which words you dropped or changed.
- Installs as an app: in Chrome on a Mac use Install from the address bar, and on an iPhone use Share, then Add to Home Screen in Safari.

Listening for your lines uses the browser's speech recognition, which works best in Chrome.
